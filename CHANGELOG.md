# Changelog

All notable changes to this Redmine Services maintained port are documented in
this file.

## [0.2.0] - 2026-08-26

### Changed

- Added compatibility with Redmine 5.x and 6.x and their supported Rails
  versions.
- Updated controller integration for modern Rails plugin loading.
- Added project-list exports.
- Prepared the project for independent publication and automated CI.

### Credits
